## Use the data

Every talk is also in `data/<series>/<edition>/talks.jsonl`, one JSON object per line. See [`schema/talk.schema.json`](schema/talk.schema.json).

Summaries are AI-assisted. Spot a mistake? [Open an issue](../../issues/new).
